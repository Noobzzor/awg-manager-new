# AWG Manager VPS Gateway — продукт

## Конечная цель

Самостоятельный Docker/Linux VPS Gateway без зависимости от Keenetic/NDMS. Удалённый телефон или компьютер подключается по AWG/WireGuard. Пользователь через единую веб-панель на VPS управляет клиентами, выходами и правилами. Решение о маршруте принимает сервер.

## Обязательные возможности

- Отдельные клиенты, ключи, адреса, профили, enable/disable/revoke, экспорт конфигурации.
- VPN / WARP / DIRECT / BLOCK для разных направлений одного клиента.
- Правила по domain/suffix/ruleset, IP/CIDR, портам и транспортным протоколам; явные приоритет и default action.
- DIRECT — выход с VPS; это не локальный обход VPN через провайдера устройства.
- VPN/WARP fail-closed: нет скрытого перехода в DIRECT при недоступности выбранного выхода. BLOCK не имеет обходного fallback.
- DNS не обходит политику; изоляция клиентов и административного интерфейса.
- Persistence, безопасное применение/rollback, restart/recovery, backup/restore с защитой секретов.
- Реальные проверки клиентского трафика и ответы, а не только корректная конфигурация.

## Границы

IPv4-only первая версия соответствует исходному контракту; это не отказ от будущего расширения. Проверка на одном клиенте не ограничивает конечный продукт одним клиентом. Платформа не превращается в локальное клиентское приложение или простой генератор профилей.

Пользователь — Product Owner. Техническую реализацию, порядок работ и тестовую среду можно менять; удаление или существенная замена возможностей требует решения пользователя. Исходная лицензия и атрибуция сохраняются.

## Необходимые различия

REQUIREMENT — что должен уметь продукт. IMPLEMENTATION — как это реализовано. EVIDENCE — точная версия, команда, результат и артефакт, подтверждающий критерий. Unit/config/API smoke не закрывают packet/VPS gate.
